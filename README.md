# Inventory-Demand-Forecasting-using-Machine-Learning
Project Overview

This project aims to predict future inventory demand using historical sales data. Accurate demand forecasting helps businesses reduce stock-outs and overstock situations by planning inventory efficiently.

Technologies Used 

Python
Pandas, NumPy
Matplotlib, Seaborn
Scikit-learn
Jupyter Notebook

Project Structure

│

How to Run

Clone the repository:  git clone https://github.com/yourusername/Inventory-Demand-Forecasting-using-Machine-Learning.git

Navigate to project folder:  cd Inventory-Demand-Forecasting-using-Machine-Learning

Open notebook:  jupyter notebook

Run w12345678_KF7032.ipynb

Output  : The model forecasts product demand and visualizes actual vs predicted sales to assist in inventory planning.
